# Anexo A3: Plantilla para diseñar una pieza de contenido emocional

<!-- Requirement: 9.3 -->
<!-- Basada en contenido de los Capítulos 6, 10 y 11 -->

Esta plantilla te guía paso a paso para diseñar una publicación que active una respuesta emocional específica en tu audiencia. Funciona para cualquier formato (reel, carrusel, caption, video largo, newsletter) adaptando las secciones al medio.

---

## Paso 1: Definir la intención emocional

Antes de escribir una palabra o grabar un segundo, responde estas tres preguntas:

| Pregunta | Respuesta |
|----------|-----------|
| **¿Qué quiero que mi audiencia sienta?** (una emoción, no un concepto) | |
| **¿Qué quiero que haga después?** (acción concreta: guardar, compartir, hacer clic, reflexionar) | |
| **¿Por qué esta emoción impulsa esa acción?** (ver mapa emocional, Anexo A2) | |

**Emociones centrales de referencia:** curiosidad, empatía, nostalgia, admiración, humor, miedo constructivo, deseo, esperanza.

---

## Paso 2: Diseñar el hook (primeros 3 segundos)

Elige uno de los cuatro mecanismos de hook (ver Capítulo 10) y redacta tu apertura:

| Mecanismo | Ejemplo de estructura | Tu hook |
|-----------|----------------------|---------|
| **Intriga** | "Esto casi se siente ilegal" / "Nadie habla de esto, pero..." | |
| **Tensión** | "Cometí un error que me costó [X] y esto aprendí" | |
| **Identificación** | "Si sientes que [experiencia común], esto es para ti" | |
| **Sorpresa** | "El consejo que más me costó aceptar sobre [tema]" | |

**Checklist del hook:**
- [ ] Activa una respuesta en menos de 3 segundos
- [ ] No revela todo (genera necesidad de continuar)
- [ ] Es coherente con la emoción central de la pieza
- [ ] No promete más de lo que el contenido entrega

---

## Paso 3: Estructurar el cuerpo

Elige la estructura narrativa más adecuada (ver Capítulo 9):

### Opción A: Problema → Mecanismo → Aplicación
Para contenido educativo con fundamento.

| Elemento | Contenido |
|----------|-----------|
| **Problema** (lo que tu audiencia enfrenta) | |
| **Mecanismo** (por qué ocurre — el "cómo funciona") | |
| **Aplicación** (qué puede hacer tu audiencia con esto) | |

### Opción B: Antes → Momento de cambio → Después
Para contenido basado en transformación personal.

| Elemento | Contenido |
|----------|-----------|
| **Antes** (situación de partida, emoción de frustración/dolor) | |
| **Momento de cambio** (qué descubriste, entendiste o hiciste) | |
| **Después** (resultado + aprendizaje transferible) | |

### Opción C: Creencia común → Evidencia contraria → Nueva perspectiva
Para contenido que desafía supuestos.

| Elemento | Contenido |
|----------|-----------|
| **Creencia común** (lo que tu audiencia asume como verdad) | |
| **Evidencia contraria** (dato, caso o experiencia que la contradice) | |
| **Nueva perspectiva** (cómo cambia esto lo que deberían hacer) | |

---

## Paso 4: Definir el tono y ritmo emocional

| Elemento | Decisión |
|----------|----------|
| **Tono** (cercano, provocador, vulnerable, experto, cómplice) | |
| **Persona narrativa** (tú directo, tercera persona para caso, alternancia) | |
| **Ritmo** (oraciones cortas para urgencia, largas para reflexión, alternancia) | |
| **Palabras clave emocionales** (3-5 palabras que quieres que resuenen) | |

**Ver Capítulo 11** para profundizar en escritura para el oído (video) vs. para el ojo (texto).

---

## Paso 5: Diseñar el cierre y CTA

| Elemento | Contenido |
|----------|-----------|
| **Emoción de cierre** (¿con qué sensación quiero dejar al espectador?) | |
| **CTA explícito** (qué acción pido — guardar, compartir, comentar, clic) | |
| **CTA implícito** (qué acción el contenido motiva sin pedirla) | |

**Regla:** El CTA debe ser coherente con la emoción generada. Si activaste empatía, pide que compartan con alguien que lo necesite. Si activaste curiosidad, invita a explorar más. Si activaste deseo, señala el siguiente paso.

---

## Paso 6: Checklist final antes de publicar

- [ ] La pieza activa una emoción específica, no varias difusas
- [ ] El hook funciona en los primeros 3 segundos
- [ ] El cuerpo tiene estructura narrativa (no es una lista de ideas sueltas)
- [ ] El tono es coherente con mi identidad emocional de marca (ver Capítulo 6)
- [ ] Hay al menos un elemento de valor concreto (dato, framework, paso aplicable)
- [ ] El cierre deja una impresión emocional clara
- [ ] El CTA es coherente con la emoción activada
- [ ] No prometo más de lo que entrego
- [ ] Los ejemplos son del ecosistema de creadores (no corporativos)

---

## Ejemplo rápido completado

| Campo | Ejemplo |
|-------|---------|
| Emoción central | Identificación + alivio |
| Formato | Carrusel Instagram (8 slides) |
| Hook | "Cosas que nadie te dice cuando llevas 6 meses creando contenido" |
| Mecanismo de hook | Identificación |
| Estructura | Problema (la soledad del creador intermedio) → Validación (es normal) → Reframe (es señal de crecimiento) |
| Tono | Cercano, cómplice, vulnerable |
| CTA | "Guárdalo para esos días en que necesitas leer esto" |
| Emoción de cierre | Esperanza con base realista |
