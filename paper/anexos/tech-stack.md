# Anexo A7: Tech stack recomendado por fase del creador

<!-- Requirement: 9.7 -->
<!-- Organizado por función y fase del creador -->

Este anexo organiza las herramientas recomendadas según la función que cumplen y la fase del creador. No necesitas todas desde el principio. Empieza con lo esencial para tu fase y añade a medida que tu operación lo justifique.

**Principio:** La herramienta correcta es la que usas de forma consistente, no la más completa ni la más cara. Mejor una herramienta simple que dominas que cinco premium que no aprovechas.

---

## Fase 1: Creador en crecimiento (0-5K seguidores)

Prioridad: producir contenido con consistencia y empezar a capturar emails.

| Función | Herramienta recomendada | Alternativa | Notas |
|---------|------------------------|-------------|-------|
| **Edición de video** | CapCut (gratuito) | InShot | Suficiente para reels y TikTok. Plantillas incluidas. |
| **Diseño gráfico** | Canva (gratuito) | | Carruseles, portadas, stories. Las plantillas aceleran la producción. |
| **Gestión de redes** | Publicación nativa desde cada app | Later (plan gratuito) | En esta fase, la programación no es crítica. La consistencia sí. |
| **Email marketing** | MailerLite (gratuito hasta 1K) | ConvertKit (gratuito hasta 1K) | Captura emails desde el primer día. No esperes a tener audiencia "grande". |
| **Landing page** | Carrd ($19/año) | Bio de Instagram con Linktree | Una página simple para lead magnet es suficiente. |
| **Almacenamiento** | Google Drive (gratuito) | | Organiza assets: fotos, videos, borradores, templates. |
| **Análisis** | Analytics nativos de cada plataforma | | Instagram Insights, TikTok Analytics, YouTube Studio. Aprende a leerlos. |

## Fase 2: Creador establecido (5K-50K seguidores)

Prioridad: sistematizar la producción, crecer la lista de email y preparar monetización.

| Función | Herramienta recomendada | Alternativa | Notas |
|---------|------------------------|-------------|-------|
| **Edición de video** | CapCut Pro o DaVinci Resolve (gratuito) | Adobe Premiere Rush | DaVinci es profesional y gratuito. Curva de aprendizaje moderada. |
| **Diseño gráfico** | Canva Pro | Figma (gratuito para uso personal) | Canva Pro desbloquea marca compartida y redimensionado automático. |
| **Gestión de redes** | Metricool o Later | Buffer, Hootsuite | Programación, analytics cruzados, mejor gestión del tiempo. |
| **Email marketing** | ConvertKit | Beehiiv, MailerLite | Automatizaciones, secuencias de nurturing, segmentación. |
| **Landing pages** | ConvertKit Landing Pages | Carrd, Systeme.io | Integración directa con email marketing simplifica el funnel. |
| **Planificación de contenido** | Notion | Trello, Airtable | Calendario editorial, banco de ideas, seguimiento de métricas. |
| **Link in bio** | Stan Store o Beacons | Linktree Pro | Permiten vender directamente desde el link. |
| **SEO / Keywords** | TubeBuddy (YouTube), VidIQ | Keyword Tool | Para optimizar títulos, descripciones y tags. Ver Capítulo 13. |
| **Análisis avanzado** | Metricool, Iconosquare | Not Just Analytics | Métricas cruzadas, reportes comparativos, tracking de crecimiento. |

## Fase 3: Creador profesional / Negocio (50K+ o monetización activa)

Prioridad: escalar operación, delegar, automatizar y proteger márgenes.

| Función | Herramienta recomendada | Alternativa | Notas |
|---------|------------------------|-------------|-------|
| **Edición de video** | Adobe Premiere Pro o DaVinci Resolve | Final Cut Pro (Mac) | Flujos de trabajo profesionales, colaboración con editores. |
| **Diseño gráfico** | Canva Pro (equipo) + Figma | Adobe Creative Suite | Canva para velocidad; Figma/Adobe para piezas premium. |
| **Gestión de redes** | Metricool Business o Sprout Social | Hootsuite Business | Gestión de equipo, aprobaciones, reportes para clientes/patrocinadores. |
| **Email marketing** | ConvertKit Creator Pro | ActiveCampaign, Beehiiv | Segmentación avanzada, commerce integrado, referral program. |
| **Plataforma de cursos** | Teachable o Thinkific | Hotmart (fuerte en LATAM), Kajabi | Hotmart tiene mayor penetración en mercado hispanohablante. |
| **Membresía / comunidad** | Circle o Discord (con bots) | Skool, Patreon | Circle para comunidades premium; Discord para comunidades amplias. |
| **Automatización** | Zapier o Make (Integromat) | n8n (self-hosted) | Conectar herramientas: nuevo suscriptor → tag → secuencia → notificación. |
| **Contabilidad / pagos** | Stripe + herramienta local | PayPal Business, Mercado Pago (LATAM) | Stripe para global; Mercado Pago para audiencia LATAM. |
| **Gestión de proyectos** | Notion (equipo) o ClickUp | Asana | Cuando delegas, necesitas visibilidad sobre quién hace qué. |
| **IA para producción** | ChatGPT / Claude para borradores, Opus Clip para clips | Descript (transcripción + edición) | Usar IA como multiplicador, no como reemplazo de voz. Ver Capítulo 24. |
| **CRM** | ConvertKit + Notion | HubSpot (gratuito) | Para gestionar relaciones con marcas, sponsors y colaboradores. |

## Herramientas transversales (útiles en cualquier fase)

| Función | Herramienta | Notas |
|---------|------------|-------|
| **Banco de ideas** | Notion, Apple Notes, Google Keep | Captura ideas en el momento. La herramienta importa menos que el hábito. |
| **Transcripción** | Descript, Whisper (gratuito) | Transcribir videos para reutilizar como texto (newsletters, carruseles). |
| **Almacenamiento en la nube** | Google Drive, Dropbox | Backup de assets, compartir con colaboradores. |
| **Tipografías y recursos** | Google Fonts, Unsplash, Pexels | Recursos gratuitos para diseño. |
| **Acortador de enlaces** | Bitly, Short.io | Para trackear clics desde bio y stories. |

---

## Criterios para elegir herramientas

1. **¿Resuelve un problema real que tienes ahora?** No adoptes herramientas "por si acaso."
2. **¿La vas a usar de forma consistente?** Si no, es una distracción, no una solución.
3. **¿Se integra con lo que ya usas?** Una herramienta aislada crea más trabajo del que ahorra.
4. **¿El coste se justifica con tu nivel de ingresos?** Empieza con gratuitas, paga cuando el ROI es claro.
5. **¿Puedes migrar tus datos si cambias?** Evita herramientas que secuestren tu contenido o lista.
