# Anexo A4: Plantilla de funnel de conversión para creadores

<!-- Requirement: 9.4 -->
<!-- Basada en contenido del Capítulo 20 -->

Esta plantilla te guía para diseñar un funnel de conversión completo: desde el primer contacto con tu contenido hasta la venta. Incluye tanto el funnel técnico (las etapas y herramientas) como el funnel emocional (la progresión de confianza que necesita ocurrir antes de que alguien compre).

---

## Principio fundamental

El funnel emocional precede al funnel técnico. Si una persona no ha recorrido la progresión curiosidad → confianza → deseo → seguridad, ninguna landing page ni secuencia de emails va a convertirla. Diseña primero la progresión emocional; luego monta la infraestructura técnica.

---

## Paso 1: Define tu oferta y tu comprador

| Campo | Respuesta |
|-------|-----------|
| **¿Qué vendes?** (producto, servicio, membresía, curso) | |
| **¿Qué problema resuelve?** (en una frase) | |
| **¿Quién es tu comprador ideal?** (no tu seguidor general, sino quien pagaría) | |
| **¿Qué necesita sentir para comprar?** (confianza, urgencia, seguridad, deseo) | |
| **Precio y modelo** (pago único, suscripción, escalado) | |

---

## Paso 2: Diseña el funnel emocional

Antes de pensar en herramientas, define qué emoción necesitas generar en cada etapa.

| Etapa emocional | Emoción objetivo | ¿Cómo la generas? | Contenido/acción |
|----------------|------------------|-------------------|-----------------|
| **Descubrimiento** | Curiosidad + relevancia | Contenido que nombra un problema que tu audiencia reconoce | |
| **Interés** | "Esta persona sabe de lo que habla" | Contenido que demuestra competencia sin vender | |
| **Confianza** | "Puedo aprender de esta persona" | Valor gratuito consistente + prueba social + transparencia | |
| **Deseo** | "Quiero más de esto" | Contenido que muestra la transformación posible | |
| **Seguridad** | "No me voy a arrepentir" | Testimonios, garantía, demostración de resultado | |
| **Acción** | "Es el momento" | Oferta clara + CTA sin presión artificial | |

---

## Paso 3: Diseña el funnel técnico

Ahora traduce cada etapa emocional a un punto de contacto concreto.

### Etapa 1: Contenido de atracción (Tope del funnel)

| Elemento | Detalle |
|----------|---------|
| **Plataforma principal** | |
| **Formato** (reel, carrusel, video, hilo) | |
| **Frecuencia** | |
| **Objetivo** | Generar descubrimiento y seguimiento |
| **Métrica clave** | Alcance, nuevos seguidores, guardados |
| **Ejemplo de pieza** | |

### Etapa 2: Lead magnet (Captura de email)

| Elemento | Detalle |
|----------|---------|
| **Tipo de lead magnet** (guía, plantilla, mini-curso, checklist, caso de estudio) | |
| **Promesa específica** (qué obtiene la persona) | |
| **Formato de entrega** (PDF, email, video, acceso a plataforma) | |
| **Landing page** (herramienta: ConvertKit, Mailchimp, Carrd, propia) | |
| **CTA desde redes** (cómo diriges tráfico al lead magnet) | |

### Etapa 3: Secuencia de nurturing (Email)

Diseña una secuencia de 5-7 emails que construya la progresión emocional.

| Email | Día de envío | Objetivo emocional | Contenido |
|-------|-------------|-------------------|-----------|
| 1. Bienvenida | Día 0 | Reciprocidad + expectativa | Entrega el lead magnet + presenta quién eres (breve) + anticipa lo que viene |
| 2. Valor puro | Día 2 | Competencia + confianza | Caso de estudio, framework aplicable o análisis útil |
| 3. Historia | Día 4 | Identificación + conexión | Tu historia relevante o la de un creador como tu lector |
| 4. Prueba social | Día 7 | Seguridad + deseo | Testimonios, resultados, transformaciones reales |
| 5. Presentación de oferta | Día 9 | Deseo + claridad | Presenta tu producto/servicio sin presión |
| 6. Objeciones | Día 11 | Seguridad | Responde las dudas más comunes con honestidad |
| 7. Cierre | Día 14 | Decisión | Última invitación + resumen del valor |

### Etapa 4: Página de venta

| Elemento | Detalle |
|----------|---------|
| **Headline** (promesa central) | |
| **Para quién es** (descripción del comprador ideal) | |
| **Qué incluye** (entregables concretos) | |
| **Testimonios / prueba social** | |
| **Precio y opciones de pago** | |
| **Garantía** (si aplica) | |
| **FAQ** (objeciones frecuentes resueltas) | |
| **CTA final** | |

---

## Paso 4: Define tus métricas por etapa

| Etapa | Métrica clave | Benchmark orientativo |
|-------|--------------|----------------------|
| Contenido → Seguidor | Tasa de seguimiento desde alcance | 1-5% |
| Seguidor → Suscriptor de email | Tasa de conversión a lead magnet | 2-8% de los seguidores activos |
| Suscriptor → Apertura de email | Open rate | 30-50% |
| Apertura → Clic | Click-through rate | 2-5% |
| Visita a página de venta → Compra | Tasa de conversión | 1-5% (varía por precio) |

---

## Paso 5: Checklist del funnel completo

- [ ] Cada etapa tiene un objetivo emocional definido (no solo técnico)
- [ ] El lead magnet resuelve un problema real y específico
- [ ] La secuencia de email construye confianza antes de vender
- [ ] La página de venta refleja la emoción que el nurturing construyó
- [ ] El precio es coherente con el valor percibido que el funnel ha construido
- [ ] No hay urgencia artificial ni escasez falsa (ver Capítulo 21)
- [ ] Las métricas están definidas y son medibles
- [ ] El funnel funciona como recorrido (no hay saltos de "te descubrí" a "cómprame")

---

## Variante para audiencias pequeñas (< 5.000 seguidores)

Si tu audiencia es pequeña, el funnel se simplifica pero los principios son los mismos:

1. **Contenido de atracción:** Enfócate en una plataforma y un formato.
2. **Lead magnet:** Puede ser tan simple como un PDF de una página o un email con un recurso.
3. **Nurturing:** Puede ser tu newsletter regular en lugar de una secuencia automatizada.
4. **Venta:** Puede ser un DM personalizado o una invitación en tu newsletter.

El volumen es menor, pero la conversión suele ser mayor porque la relación es más cercana.
