# Anexo A8: Ejercicios de observación y análisis de contenido viral

<!-- Requirement: 9.8 -->

Estos ejercicios están diseñados para entrenar tu capacidad de analizar por qué cierto contenido funciona, más allá de "tuvo suerte" o "es famoso." Cada ejercicio aplica conceptos del libro a contenido real que tú observas. Hazlos con regularidad (uno por semana es suficiente) para desarrollar el ojo analítico que separa al creador estratégico del creador que solo imita.

---

## Ejercicio 1: Desmontaje de hook (15 minutos)

**Basado en:** Capítulo 10 (El gancho: los primeros 3 segundos)

### Instrucciones

1. Abre TikTok, Instagram Reels o YouTube Shorts.
2. Haz scroll durante 2 minutos y anota las 3 publicaciones donde te detuviste involuntariamente.
3. Para cada una, completa esta ficha:

| Campo | Publicación 1 | Publicación 2 | Publicación 3 |
|-------|--------------|--------------|--------------|
| Plataforma y formato | | | |
| ¿Qué viste/oíste en los primeros 3 segundos? | | | |
| ¿Qué mecanismo de hook usó? (intriga, tensión, identificación, sorpresa) | | | |
| ¿Qué emoción activó? | | | |
| ¿Seguiste viendo o te fuiste? ¿Por qué? | | | |
| ¿El contenido cumplió la promesa del hook? | | | |

### Reflexión

- ¿Qué patrón comparten los hooks que te detuvieron?
- ¿Puedes adaptar ese patrón a tu nicho? ¿Cómo sonaría?
- Redacta 3 hooks para tu próxima publicación usando los mecanismos que identificaste.

**Basado en:** Capítulo 14 (Ingeniería de la viralidad)

2. Completa el análisis:

**Datos básicos:**

| Campo | Respuesta |

| Formato | |

| Métricas visibles (views, likes, comentarios, compartidos) | |
| Fecha de publicación | |

**Análisis de mecanismos:**

| Pregunta | Respuesta |
|----------|-----------|

## Ejercicio 3: Mapa emocional de comentarios (20 minutos)

**Basado en:** Capítulos 3 y 5 (emociones y audiencia)

### Instrucciones

1. Elige una de tus publicaciones recientes con al menos 20 comentarios.
2. Lee los primeros 30 comentarios y clasifica cada uno por la emoción que expresa.

| Categoría emocional | Cantidad | Ejemplo de comentario |
|--------------------|----------|----------------------|
| Identificación ("me siento visto/a", "esto soy yo") | | |
| Admiración ("increíble", "eres genial") | | |
| Gratitud ("necesitaba esto", "gracias") | | |
| Humor (emojis de risa, chistes) | | |
| Debate ("no estoy de acuerdo", "pero...") | | |
| Acción ("lo voy a probar", "ya lo hice") | | |
| Vacío ("", "fuego", sin contenido emocional claro) | | |

### Reflexión

- ¿Cuál es la emoción dominante que genera tu contenido actual?
- ¿Es coherente con tu identidad emocional de marca? (ver Capítulo 6)
- ¿Los comentarios con más carga emocional corresponden a tu contenido con mejor rendimiento?
- Si tuvieras que aumentar un tipo de comentario, ¿cuál sería y por qué?

## Ejercicio 4: Análisis comparativo de formatos (25 minutos)

**Basado en:** Capítulo 16 (Contenido por formato)

### Instrucciones

1. Busca a un creador de tu nicho que publique en al menos 2 formatos diferentes (ejemplo: reels + carruseles, o videos largos + shorts).
2. Analiza 3 publicaciones de cada formato.

| Criterio | Formato A: _______ | Formato B: _______ |
|----------|--------------------|--------------------|
| Tipo de contenido que publican | | |
| Emoción dominante | | |
| Tipo de engagement que genera (likes vs. comentarios vs. guardados) | | |
| Profundidad del contenido | | |
| Tipo de audiencia que atrae (nuevos vs. existentes) | | |
| Rendimiento relativo (alcance, engagement rate) | | |

### Reflexión

- ¿Cada formato cumple una función diferente en su estrategia?
- ¿El formato potencia el mensaje o lo limita?
- ¿Hay un formato que funcione mejor para un tipo de contenido específico?
- ¿Qué puedes aplicar a tu propia estrategia de formatos?

## Ejercicio 5: Deconstrucción de funnel (40 minutos)

**Basado en:** Capítulo 20 (Funnels de conversión)

### Instrucciones

1. Elige un creador de tu nicho que venda un producto o servicio (curso, membresía, consultoría, producto digital).
2. Sigue su funnel completo como si fueras un potencial cliente. Documenta cada paso.

| Etapa del funnel | Qué hiciste | Qué te ofrecieron | Emoción que sentiste |
|-----------------|-------------|-------------------|---------------------|
| Descubrimiento (¿cómo lo encontraste?) | | | |
| Primer contenido consumido | | | |
| ¿Te pidieron algo? (email, follow) | | | |
| Lead magnet (si existe) | | | |
| Secuencia de email / nurturing | | | |
| Momento de la oferta | | | |
| Página de venta | | | |

### Análisis

| Pregunta | Respuesta |
|----------|-----------|
| ¿El funnel emocional fue coherente de principio a fin? | |
| ¿En qué momento sentiste más confianza? ¿Por qué? | |
| ¿En qué momento sentiste fricción o desconfianza? ¿Por qué? | |
| ¿La transición de contenido gratuito a oferta fue natural o abrupta? | |
| ¿Comprarías? ¿Por qué sí o por qué no? | |

### Aplicación

Identifica 2 elementos de este funnel que puedas adaptar al tuyo. Identifica 1 error que quieras evitar.
