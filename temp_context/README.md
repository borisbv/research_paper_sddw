## Tarea principal

Revisar y corregir el manuscrito atendiendo a:

1. **Observaciones del editor** (`apreciacion_autor.md`):
   - Coherencia entre enfoque de neurodiversidad y objetivos/título/conclusiones (aún centrados en TEA)
   - Justificación de que las dificultades reportadas corresponden a necesidades cognitivas/sensoriales/emocionales de TEA
   - Inconsistencia entre el requisito de control de estímulos y el 40 % de participantes que reporta sobrecarga sensorial
   - Incorporar base pedagógica que sustente el diseño del entorno virtual (DUA u otro fundamento)

2. **Normas de la revista** (`normas_revista.md`):
   - Estructura: introducción, objeto de estudio, fundamentación teórica, metodología, desarrollo, resultados, conclusiones
   - Formato APA para citas y referencias (nombres completos de autores/as)
   - Todas las figuras citadas en el texto
   - Resumen máximo 100 palabras
   - Lenguaje inclusivo según sección 3 de las normas

3. **Convención de marcado** (según `instrucciones.md`):
   - Todo texto nuevo o modificado debe comenzar y terminar con el símbolo `*`
   - Las referencias nuevas también deben marcarse con `*`
