# Contexto Temporal de Investigación

Esta carpeta contiene los materiales base para la iteración actual del marco teórico y la estructura del paper.

## Archivos de la carpeta

- **2_mentoría.md**: Transcripción de la sesión con el mentor. Contiene feedback crítico sobre consistencia, pluralidad de citas y sugerencias de reestructuración narrativa.
- **FormulacionIniEsp_CF.docx.md**: Paper de referencia. Debe utilizarse exclusivamente como guía para entender la estructura, secciones y el nivel de profundidad esperado en el trabajo final.
- **Marco teórico - Tea Tecnologia + CF.docx.md**: Documento principal de trabajo. Es el archivo que debe ser modificado y enriquecido, integrando la nueva información y referencias siguiendo las pautas de esta guía.

## Necesidad

- Mejorar el archivo llamado (**Marco teórico - Tea Tecnologia + CF), pero manteniendo la misma narrativa. 
- Sólo se debe insertar información extra y mejoras. Toda la informacion nueva debe estar entre corchetes "[ ]"
- Los conceptos y afirmaciones teorica deben tener al menos 5 autores de referencia.  
- Los autores deben ser de revistas scopus actuales (del año 2020 al 2026).
- Citar según normas APA.

## Tono y Estilo Académico

1. **Estructura de Párrafos y Fluidez**
  - **Densidad Narrativa**: Los párrafos son concretos, diseñados para agotar una idea completa antes de pasar a la siguiente. Se evita la fragmentación para mantener un hilo conductor sólido.
  - **Prosa Continua**: No se utilizan guiones (-) ni elementos disruptivos dentro de los párrafos. La puntuación se limita a comas y puntos seguidos para priorizar una redacción fluida y natural.
  - **Transiciones Académicas**: Uso frecuente de conectores lógicos para iniciar párrafos o ideas (e.g., "En este contexto...", "Asimismo...", "Siguiendo esta tendencia...", "Por otro lado...").

2. **Énfasis y Formato Visual**
  - **Resaltado de Hallazgos**: Se utiliza negrita dentro de los párrafos para destacar conceptos clave o categorías emergentes.
  - **Tecnicismos en Itálicas**: Los términos técnicos en inglés o conceptos metodológicos específicos se escriben en cursiva (e.g., *User Experience*, *Design Thinking*, *sprints*).
  - **Uso de Notas al Pie**: Las aclaraciones legales o técnicas que podrían romper el flujo de la prosa se desplazan a notas al pie ([^1]).

3. **Integración de Evidencia Cualitativa**
  - **Voces de los Sujetos**: Las citas directas de los participantes se presentan como párrafos independientes, con sangría o formato diferenciado.
  - **Tratamiento de Verbatim**: Se respetan las expresiones originales usando [sic] y se insertan aclaraciones entre corchetes para dar contexto sin alterar la voz del entrevistado.
  - **Identificación Anónima**: Cada cita termina con un paréntesis que indica el perfil general del sujeto.

4. **Rigor Científico y Citación**
  - **Anclaje Bibliográfico**: Prácticamente cada afirmación de contexto está respaldada por una cita parentética (Autor, Año). Se utiliza el formato "Autor (Año) señala que..." o "(Autor, Año)" al final de la frase.
  - **Referenciación Cruzada**: El texto dialoga constantemente con sus propios recursos visuales, utilizando indicaciones explícitas como "(ver Tabla 1)" o "Figura 1. Categorías que...".

5. **Tono y Vocabulario**
  - **Equilibrio Humanista-Técnico**: El lenguaje es formal y científico, reforzando el enfoque humano del estudio.
  - **Precisión Terminológica**: Uso riguroso de términos técnicos para validar la autoridad del texto.
