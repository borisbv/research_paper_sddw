# Contexto Temporal de Investigación: Revisión y Metodología UX

Este directorio contiene los materiales necesarios para la iteración y mejora del proyecto de investigación **"HabiTAR: Impacto de las tecnologías digitales en la autorregulación emocional y su relación con la inclusión académica de estudiantes universitarios con CEA"**.

## Estructura de Archivos

| Archivo | Función |
| :--- | :--- |
| `instrucciones.md` | **Prompt Maestro.** Contiene las directrices de alto nivel para el procesamiento del documento, incluyendo el rol esperado, las restricciones de edición y los requisitos metodológicos. |
| `Copia de EA + Marco teórico V2 + CF.docx.md` | **Documento Fuente.** Es el borrador actual del marco teórico. Contiene etiquetas **`($)`** que marcan los puntos específicos donde el revisor ha solicitado cambios. |
| `Nota de Revisor -3 SESIÓN_.md` | **Contexto Adicional.** Transcripción detallada de la sesión de retroalimentación. Sirve como referencia profunda para entender el "por qué" de las correcciones y el tono académico deseado. |

## Flujo de Trabajo Sugerido

1. **Análisis de Retroalimentación:** Revisar la `Nota de Revisor -3 SESIÓN_.md` para captar los matices del revisor (evitar lenguaje de negación, uso de términos CEA vs TEA, importancia del ciclo vital universitario).
2. **Ejecución de Cambios:** Seguir el prompt de `instrucciones.md` para modificar el `Documento Fuente`.
3. **Desarrollo Metodológico:** Diseñar la sección de Metodología UX tras los objetivos específicos, asegurando el respaldo bibliográfico.
4. **Validación:** Verificar que no se hayan modificado áreas sin etiquetas `($)` y que el tono sea de prosa fluida (sin bullets innecesarios).
