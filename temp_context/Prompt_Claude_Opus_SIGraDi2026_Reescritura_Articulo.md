# **20\. DESARROLLO DEL MARCO TEÓRICO**

El marco teórico constituye la principal oportunidad de fortalecer este artículo.

No debe limitarse a aumentar el número de referencias.

Debe construir un verdadero estado del arte internacional.

Cada apartado debe:

* comenzar presentando el estado actual del conocimiento;   
* comparar investigaciones recientes;   
* identificar acuerdos y diferencias entre autores;   
* analizar críticamente la literatura;   
* explicar cómo ese conocimiento conduce hacia la brecha de investigación. 

No utilizar referencias únicamente para respaldar afirmaciones.

Las referencias deben formar parte de una discusión científica.

El lector debe percibir una evolución del conocimiento y no una simple recopilación bibliográfica.

---

# **21\. CONSTRUCCIÓN DE LA BRECHA DE INVESTIGACIÓN**

La brecha de investigación no debe redactarse mediante afirmaciones negativas.

Evita expresiones como:

* "No existen investigaciones..."   
* "La literatura no aborda..."   
* "No hay evidencia..." 

En su lugar construye la brecha mediante una evolución argumentativa.

Por ejemplo:

La literatura ha realizado avances significativos en museos virtuales, patrimonio digital, experiencia de usuario y tecnologías inmersivas. Sin embargo, estos desarrollos han sido abordados mayoritariamente desde perspectivas independientes, generando una oportunidad para explorar modelos integradores que articulen estos componentes dentro de un marco metodológico común.

La brecha debe representar una oportunidad científica.

Nunca una crítica.
